# SOC Lab Setup & Network Traffic Analysis

A hands-on cybersecurity lab project focused on setting up a virtual security testing environment and investigating network traffic using Wireshark.

## Project Overview

This project involved deploying Kali Linux in Oracle VirtualBox, configuring the virtual lab environment, and performing practical network traffic analysis to understand common security events and attack techniques.

The work combines virtual lab deployment with packet-level investigation using Wireshark.

## Lab Environment Setup

The following tasks were completed:

- Installed and configured Oracle VirtualBox.
- Deployed Kali Linux as a virtual machine.
- Configured a NAT Network using `10.0.0.0/24`.
- Configured the Kali Linux network interface with `10.0.0.2/24`.
- Enabled host-to-guest shared folder access.
- Configured clipboard and drag-and-drop functionality.
- Tested network and internet connectivity.
- Created a virtual machine snapshot for recovery.

## Wireshark Traffic Analysis

Practical exercises were performed to investigate different network security scenarios.

| Exercise | Analysis |
|---|---|
| Lab 3 | Port scanning detection and attacker identification |
| Lab 4 | TCP stream analysis and session inspection |
| Lab 6 | HTTP plain-text credential exposure |
| Lab 7 | FTP brute-force attack investigation |
| Lab 8 | VoIP traffic analysis using SIP and RTP |

## Tools & Technologies

## Key Learning Outcomes

- Building and configuring a virtual cybersecurity lab.
- Understanding virtual networking and host-to-guest communication.
- Capturing and inspecting network traffic.
- Identifying suspicious network activity.
- Investigating authentication-related attacks.
- Understanding the security risks of unencrypted communication.
- Analyzing SIP and RTP network traffic.

## Project Purpose

The objective was to gain practical experience in cybersecurity lab deployment, network investigation, and fundamental SOC analysis techniques.
